# Coffee's Ready!

A small, friendly Flutter app for making French press coffee. Two things, done well:

- **Water calculator** — enter the coffee weight and it shows how much water to add. Defaults: 14 g coffee, 1:16 ratio (224 ml).
- **Brew timer** — starts at 2:25, with 2:15 / 2:25 / 2:35 presets and 5-second fine tuning. The presets can be edited in Settings. When the timer finishes you get an **Enjoy!** notification with **Stop** and **+15 s** actions. The app ships with the Android Clock timer sound as its default; tap any sound in Settings to preview it.

The coffee-to-water ratio and alarm sound are saved on the device.

## Android

Built and tested with Flutter 3.50.1 and Android SDK 36/37.

```sh
flutter pub get
flutter run
flutter build apk --release
```

The APK lands at `build/app/outputs/flutter-apk/app-release.apk`.

Release builds are currently signed with the debug key. Replace the signing config with your own keystore before publishing.

### Copy the APK to your phone with ADB

Android Platform Tools (`adb`) is the quickest way to get the build onto a phone. On the phone, enable **Developer options → USB debugging**, connect it over USB, and allow the debugging prompt.

Check that the phone is connected:

```sh
adb devices
```

You should see your phone's serial number followed by `device`.

Copy the APK to the phone's Downloads folder:

```sh
adb push build/app/outputs/flutter-apk/app-release.apk /sdcard/Download/CoffeeReady.apk
```

Then open `CoffeeReady.apk` on the phone with a file manager and allow installs from that app. Alternatively, install it directly over USB:

```sh
adb install -r build/app/outputs/flutter-apk/app-release.apk
```

Launch the app:

```sh
adb shell am start -n com.kinonn.coffee_timer/.MainActivity
```

`adb install -r` keeps existing settings. If `adb` is not on your `PATH`, use the copy from the Android SDK; on Windows the command is usually:

```powershell
& "$env:LOCALAPPDATA\Android\Sdk\platform-tools\adb.exe" devices
```

### How the alarm works

`android/app/src/main/kotlin/com/kinonn/coffee_timer/MainActivity.kt` exposes a small `coffee_timer/native` method channel:

- lists the phone's alarm tones via `RingtoneManager` (`TYPE_ALARM`)
- ships with the Android Clock timer sound as the default alarm and previews sounds in Settings
- plays the chosen tone on the alarm audio stream and loops until stopped
- posts an **Enjoy!** completion notification with **Stop** and **+15 s** actions
- stores the ratio, presets, and chosen alarm in native `SharedPreferences`

No plugins. The only permission is Android 13's notification permission, requested when you start the timer.

The bundled timer sound is `timer_expire.ogg` from the AOSP DeskClock app, used under the Apache License 2.0.

## iOS

The project is generated for Android only. On a Mac with Xcode:

1. Install Flutter, Xcode, and CocoaPods, then run `flutter doctor`.
2. From the project root: `flutter create --platforms=ios .`
3. `cd ios && pod install`
4. `open ios/Runner.xcworkspace`, then choose your team and bundle identifier under Runner → Signing & Capabilities.
5. `flutter run` (or build with `flutter build ios`).

The Dart UI runs on iOS as-is, but the `coffee_timer/native` bridge is Android-only. For matching behaviour, add the same channel in `AppDelegate.swift` using `AVAudioPlayer` and iOS system sounds, and keep the settings in `UserDefaults`. Without it, the app uses the defaults, settings won't persist, and the timer alarm stays silent.

## Notes

The alarm and completion notification are posted while the app process is alive. For an alarm that survives the app being killed, the next step would be a foreground service with a full-screen notification.
